# Compiler site visual contract

The public Compiler site is the presentation surface for the derived catalog.
This contract aligns it with the Portfolio 2071 interface language without
coupling the two sites or copying Portfolio's research/runtime features.

## Shared 2071 tokens

The shell uses the `TJHG / experiments` wordmark, a fixed 58px navigation rail,
compact monospace labels, and the bundled Long Measure display face for titles
and catalog names. The default light environment is blue-white; the dark
environment is blue-black:

| Role | Light | Dark |
| --- | --- | --- |
| field | `#f4f9fd` | `#00070d` |
| ink | `#071724` | `#edf7ff` |
| muted | `#425768` | `#9db5c6` |
| rule | `#9bb2c3` | `#24445c` |
| active signal | `#006fc7` | `#29a7ff` |

Catalog records, package identity panels, and standards links use a restrained
refractive-glass treatment: an opaque-enough panel, a visible structural edge,
one specular highlight, and bounded blur. Contrast and reading order do not
depend on translucency, glow, or motion. The page field has no gridline or
simulated telemetry background. A single low-amplitude radial gradient follows
the reader's scroll position when motion is allowed.

## Behavior and accessibility

- Auto, Light, and Dark are explicit controls. The selected value is stored in
  `localStorage` under `experiment-theme`, with system preference used only for
  Auto. The preference is local to the Compiler site and is not synchronized
  with Portfolio.
- Catalog and detail routes share the same shell, theme controls, font, focus
  treatment, touch target minimums, reduced-motion behavior, forced-colors
  fallback, and narrow-screen layout.
- Hover and route feedback are short and mechanical. There is no scroll
  hijacking, fade-up cascade, ambient particle field, or persistent neon glow.
- The CSS `@view-transition` rule is a progressive enhancement for browsers'
  native same-origin document transitions. Compiler JavaScript only adds a
  small outgoing flash for same-origin routes. Cross-origin Research and GitHub
  links navigate normally; the site does not claim or emulate cross-origin
  View Transitions.

## Data and hosting boundary

`site/data/experiments.json` remains generated by
`scripts/build_pages_site.py`. The visual work must not change generated
catalog data, experiment IDs, exact package/source identities, scientific
status labels, protocol text, source links, or package downloads. Detail pages
remain static routes, and the existing GitHub Pages/Fleet lifecycle continues
to be the only publication path. The Compiler does not copy Portfolio's model
machine, research topology, article runtime, search, or executable notebook
features.

Validation includes the existing unit suite, generated-site build, hostile
protocol mobile check, and browser review at phone, tablet, and desktop widths.
