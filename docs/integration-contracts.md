# Cross-repository integration contracts

These are the public interfaces between source owners, Compiler, Long-Haul, the Fleet controller, and the archive. Each interface binds its own identities and establishes a distinct kind of evidence.

## Archive handoff

[Compiled Experiments](https://github.com/pH34r-pH/compiled-experiments) consumes exact source-owner-approved public package bytes with their manifest, metadata, and verification and study receipts. Promotion preserves the approved bytes and their digest. Archive verification is read-only. [Archive release procedure](https://github.com/pH34r-pH/compiled-experiments/blob/279acd76fdaf6aabda29163fdb29091f4a7f8884/RELEASING.md)

The pinned archive verifier accepts the existing #152 `compiled-experiment-v1` specimen. It checks the canonical ZIP against `SHA256SUMS` and the Compiler receipt's `packageSha256`, `packageSizeBytes` and `status`. The legacy study also has a separately retained `matched` replay receipt and a NumPy prerequisite check. Those checks describe this specimen. The current archive validator rejects the newer lifecycle package profile, so general lifecycle ingestion still needs consumer qualification under [archive #1](https://github.com/pH34r-pH/compiled-experiments/issues/1) and [archive #7](https://github.com/pH34r-pH/compiled-experiments/issues/7). [Pinned archive verifier](https://github.com/pH34r-pH/compiled-experiments/blob/279acd76fdaf6aabda29163fdb29091f4a7f8884/scripts/verify_archive.py)

For the offline audit, the pinned archive's `python scripts/verify_archive.py` passed on the committed #152 files. Compiler `verify --expected-sha256` also matched the separately recorded release-request digest `25612d81a480dd5f8148a0dc247db58cb2fd719fe619e75ef0cd4945b3c1364b` and rejected a one-byte change to a disposable copy. The verification left the archive checkout clean. [Pinned release request](https://github.com/pH34r-pH/compiled-experiments/blob/279acd76fdaf6aabda29163fdb29091f4a7f8884/release-requests/dsl-issue-152-v1.0.0.json)

The reviewed GitHub Release is the human handoff to Zenodo. Derived Compiler, manuscript, and article views can display exact authoritative archival identifiers as they become available. Missing release or DOI metadata remains unknown and leaves byte integrity and scientific evidence claims independent. [Catalog projection contract](catalog-projection.md)

## Qualification still required

- The Long-Haul guarded private-check projection, semantic trajectories, and governed corpora require separately reviewed producer evidence and Compiler profile pins. The [private-check disclosure gate](repository-agent-profiles.md#private-check-disclosure-gate) governs current public admission.
- Real native controller use requires Fleet's authenticated authority, qualified native executor, durable transport, and verified worker profile. The [controller contract](native-actions-projection.md#trusted-native-controller-consumer) describes the pre-execution checks.
- The workflow and fixtures use public or synthetic evidence. Private lab source, restricted evaluator inputs, and human publication approval remain with their respective owners.
